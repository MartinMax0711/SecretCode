# 晗晗的小窝 🎀

给晗晗做的专属小网站。纯静态页面，没有后端，数据都在晗晗自己的手机里；
只有「老公铃 / 看屏幕 / 看位置」会通过 [ntfy.sh](https://ntfy.sh) 这个免费推送服务，
和耀耀电脑上的「小窝助手」说话。

## 有什么

| 页面 | 干什么 |
| --- | --- |
| 首页 · 老公铃 | 按一下，耀耀的 Mac 会响铃 + 弹窗；耀耀回的话会显示在这里 |
| 经期 | 记录、日历、预测下次经期和排卵期；来了 / 肚子痛可以顺手通知耀耀 |
| 睡眠 | 「我睡了」「我醒啦」两个按钮，统计每天睡多久 |
| 道歉信 | 耀耀写的信，晗晗可以盖「原谅」或者「哼！」的章，附一句话 |
| 课表 | 读 myschoolapp 导出的日历，显示耀耀现在在上什么课、还有多久下课 |
| 相册 | 我们的合照，可以现场加照片 |
| 解气 | 打小狗耀耀，五种工具、连击、解气值，打完可以告诉耀耀「气消了」 |
| 陪着你 | 看耀耀电脑的实时画面和大概位置（要暗号） |

## 本地看看

```bash
python3 -m http.server 4173
```

然后打开 http://localhost:4173

## 日常怎么用

**加一封道歉信** — 改 `data/letters.js`，在数组最前面加一条：

```js
{
  id: '2026-09-20',
  date: '2026-09-20',
  title: '对不起，我又……',
  content: `老婆：

……`,
},
```

**加照片** — `./mac/add-photos.sh ~/Desktop/合照/*.jpg`
（自动转 jpg、缩小、按拍摄日期命名，并更新 `data/photos.js`）

**更新课表** — 从 myschoolapp 下载日历（.ics），存成 `data/schedule.ics`。
学校时区在 `js/config.js` 的 `schoolTimeZone`，日历里带时区的话会自动用日历里的。

**改名字 / 推送频道** — 都在 `js/config.js`。改了 `ntfyTopic` 要重新跑一次 `mac/install.sh`。

## 电脑端：小窝助手

```bash
./mac/install.sh
```

装完是一个开机自启的后台服务，负责：

- 收到老公铃 → 响三声 + 弹窗，可以直接打字回复晗晗
- 收到其它消息（晗晗睡了 / 经期来了 / 拆了道歉信…）→ 系统通知
- 收到带暗号的「看一眼」请求 → 截屏 + 取位置，发回给晗晗

第一次会需要两个系统权限：

- **通知**：系统设置 › 通知 › 脚本编辑器（Script Editor）打开
- **屏幕录制**：系统设置 › 隐私与安全性 › 屏幕录制，允许 `zsh`（只有「看屏幕」要用）

日志在 `~/Library/Application Support/XiaoWo/xiaowo.log`，卸载跑 `./mac/uninstall.sh`。

## 隐私

- 经期、睡眠、相册里现场加的照片：只存在晗晗那台设备的浏览器里，不上传。
  换手机之前记得 ⚙️ › 导出备份。
- 道歉信、课表、`photos/` 里的照片是仓库的一部分 —— **仓库是公开的话，这些也是公开的**。
  建议把仓库设成私有，用 Vercel / Netlify / Cloudflare Pages 部署（私有仓库也免费）。
- 「陪着你」的截屏请求必须带暗号，暗号只存在晗晗手机里和耀耀电脑上，不在仓库里。
